1. このアプリでできること

Logic Pro で、Splice などのサンプルを聴きながら選んで、次の 3 つのどれかに入れるアプリです。

  • Quick Sampler（鍵盤で弾けるサンプラー）に読み込む
  • Drum Machine Designer（DMD）のパッドに 1 つずつ読み込んで、ドラムキットを組む
  • ループをプロジェクトのテンポとキーに合わせて、オーディオトラックに貼る

VoiceOver とキーボードだけで使えるように作っています。Logic の画面には、VoiceOver の移動では届かない部品（Quick Sampler の Sample name の欄や Flex のボタンなど）がありますが、それらはアプリが代わりに押します。

素材は、アプリが作業用のフォルダに複製してから読み込みます。Logic は読み込んだファイルそのものに情報を書き足すので、Splice の元のファイルをそのまま読み込ませないためです。

2. 動く環境と、用意するもの

表は 8 行で、列は「もの」「要るか」「説明」の 3 つです。

もの要るか説明
Apple シリコン（M1 以降）の Mac要るIntel の Mac では動きません
macOS 15 以降要る作者は macOS 15.7.8 で確かめています
Logic Pro 12.3（英語か日本語の表示）要る表示の言語は英語でも日本語でもかまいません（下の説明）
VoiceOver要る結果は VoiceOver で読み上げます
Splice の素材あると便利Splice のフォルダの素材を検索できます。無くても、ファイルを選んで読み込めます

Logic Pro の表示の言語

アプリは、Logic の部品を名前（テンポ、キー、ファイル、読み込む など）で探します。英語と日本語の両方の名前を知っているので、Logic が英語の表示でも日本語の表示でも動きます（1.2.0 から。それまでは英語の表示だけでした）。

Quick Sampler と Drum Machine Designer の画面の中は、Logic が日本語の表示でも英語のままです（Sample name、Follow Tempo、Empty Pad など）。このマニュアルでも、その名前で書いています。

ほかの言語（ドイツ語やフランス語など）の表示では、部品が見つからずに動きません。そのときは Logic だけを英語か日本語にします。システム設定の「一般」→「言語と地域」の「アプリケーション」で、追加のボタンを押して Logic Pro を選び、言語を選びます。Logic を開き直すと切り替わります。

このアプリの表示の言語（日本語・英語）

このアプリの画面・メニュー・読み上げは、Mac の言語の設定に合わせて、日本語か英語で出ます。システム設定の「一般」→「言語と地域」の「優先する言語」で、日本語が英語より上にあれば日本語、英語が上にあるか日本語が無ければ英語です。Keyboard Maestro の補助（11 章）の読み上げも同じ言語になります。

このアプリだけ言語を変えるときは、上と同じ「アプリケーション」で、追加のボタンを押して Logicサンプルローダー を選び、言語を選びます。変えたあとは、アプリを開き直します（言語は開いたときに決まります）。英語のときは、Finder でのアプリの名前も「Logic Sample Loader」になります。

Logic の画面の大きさ

Quick Sampler と Drum Machine Designer の画面は、Logic の表示の大きさ（プラグインの画面の拡大率）が 100% のときに確かめています。ほかの大きさでも合わせて探しますが、確かめてはいません。

Logic Magician を使っている方へ

このマニュアルでは、プラグインの画面を開くキーとして、Logic Magician のハイフンを書いています。Logic Magician を使っていない場合は、インスペクタのチャンネルストリップで、音源のスロットの「open」ボタンを押して開いてください。

3. 入れ方

3.1 アプリを置く

  1. 受け取った zip ファイルを Finder で開きます（選んでコマンド+O）。同じ場所に「Logicサンプルローダー_1.2.0」というフォルダができます
  2. フォルダの中の「Logicサンプルローダー.app」を、アプリケーションフォルダへ移します。Finder で .app を選んでコマンド+C、アプリケーションフォルダでオプション+コマンド+V（移動）です
  3. マニュアルなどの文書は、どこに置いてもかまいません

3.2 初めて開くとき

このアプリは、Apple による公証（ノータリゼーション）を受けていません。そのため、インターネットから受け取った zip から取り出したアプリを初めて開くと、macOS が開くのを止めることがあります。そのときは、次のどちらかで開きます。

方法 1: システム設定から開く

  1. アプリを一度開こうとします。開けないという知らせが出たら、「完了」で閉じます
  2. システム設定の「プライバシーとセキュリティ」を開き、下のほうの「セキュリティ」へ進みます。Logicサンプルローダー の使用がブロックされたという文と、「このまま開く」のボタンがあります
  3. 「このまま開く」を押し、パスワード（または Touch ID）で認めます
  4. もう一度アプリを開き、確かめる知らせが出たら「このまま開く」を選びます

macOS の版によって、文やボタンの名前が少し違うことがあります。2 回目からは、ふつうに開けます。

方法 2: ターミナルで隔離の印を外す

アプリをアプリケーションフォルダへ移してから、ターミナルで次の 1 行を実行します。

xattr -dr com.apple.quarantine "/Applications/Logicサンプルローダー.app"

インターネットから受け取ったファイルに付く「隔離」の印を外す命令です。外したあとは、ふつうに開けます。

3.3 アクセシビリティの許可

アプリは Logic の部品を押すので、アクセシビリティの許可が要ります。初めて素材を読み込もうとしたとき、macOS が許可を求める知らせを出します。

  1. 知らせの「システム設定を開く」を押します。アプリの操作メニューの「アクセシビリティの設定を開く」でも、同じ画面が開きます
  2. システム設定の「プライバシーとセキュリティ」→「アクセシビリティ」の一覧で、Logicサンプルローダー のスイッチを入れます（パスワードを求められます）
  3. アプリを終了して、開き直します。許可は、開き直したときに効きます

許可が入るまで、主画面の「読み込み先を調べる」のボタンの名前に「アクセシビリティの許可がまだありません」と出ます。

新しい版に入れ替えたとき

新しい版のアプリに入れ替えると、macOS は別のアプリとみなし、前の許可が効かなくなることがあります。「アクセシビリティの許可がありません」と言われたら、一覧の Logicサンプルローダー を削除のボタンで消してから、もう一度許可を入れてください。

このほかに、「System Events」を制御する許可を求められることがあります。読み上げの予備の方法のためで、許可しなくても使えます。

3.4 Splice のフォルダと索引

アプリは、Splice の素材の一覧（索引）を作ってから検索します。初めて使うときは、コマンド+R で索引を作ります。素材を買い足したときも、コマンド+R で作り直します。

Splice のフォルダは、ふつうはホームフォルダの「Splice」です。アプリはその中の「sounds」→「packs」を探します。Splice のフォルダを別の場所に移している場合は、操作メニューの「Splice のフォルダを選ぶ」で選びます。Splice のフォルダそのものを選べば、中のパックのフォルダをアプリが見つけます。選ぶと、そのフォルダで索引を作り直します。

Splice を使っていなくても、コマンド+O で好きなファイルを選んで読み込めます。

3.5 ffmpeg と rubberband（オーディオトラックに貼るとき）

オーディオトラックに貼る機能は、テンポとキーを合わせた音を作るために ffmpeg を使います。rubberband もあれば、伸び縮みと移調はそちらを使い、音質が上がります。どちらも Homebrew で入れます。ターミナルで次の 1 行を実行します。

brew install ffmpeg rubberband

Quick Sampler と DMD のパッドへの読み込みには、どちらも要りません。

3.6 Keyboard Maestro の補助（使うときだけ）

Logic を使いながら、コントロール+シフト+L・T・P で Quick Sampler の届かない部品を押せるようにする補助です（11 章）。Keyboard Maestro が要ります。

  1. アプリの操作メニューの「Keyboard Maestro の補助を入れる」を選びます。Keyboard Maestro が開き、マクロが 3 つ取り込まれます
  2. 取り込んだマクロは、無効の状態で入ります。Keyboard Maestro の編集画面で、グループ「Logicサンプルローダー 補助」のマクロを有効にします
  3. VoiceOver ユーティリティの「一般」で、AppleScript による VoiceOver の制御を許可しておきます（結果を読み上げるため。Logic Magician を使っているなら、すでに入っています）

もう一度選んでも、入っているマクロは取り込み直しません（二重にならないように）。アプリを別の場所に移したときは、アプリを一度開けば、マクロが新しい場所のアプリを使うようになります。

4. 画面の並び

画面は上から「素材を探す」「検索結果一覧」「読み込む」の 3 つの見出しに分かれています。アプリを開くと、検索語の欄にフォーカスがあります。

タブで止まる欄を、止まる順に並べました。シフト+タブで逆の順に戻ります。表は 14 行で、列は「順」「欄の名前」「使えるとき」の 3 つです。

「読み込む」の見出しの下には、ボタンも並んでいます（入れる、読み込みの設定、読み込み先を調べる、Flex を切り替える、ファイルを選んで読み込む）。タブでは止まりませんが、どれもキーで同じことができます（10 章）。VoiceOver の移動で着けば、リターンでもスペースでも押せます。

どこにいるか分からなくなったら、コマンド+F で検索語の欄へ、コマンド+I で検索結果一覧へ戻れます。いちばん下の行には、最後に読み上げた文が出ています。

欄に止まったあと、VoiceOver が使い方のヒントを続けて読みます。長いと感じるときは、VoiceOver ユーティリティの「冗長性」の「ヒント」で読まないようにできます（VoiceOver 全体の設定なので、ほかのアプリにも効きます）。

5. Quick Sampler に読み込む（基本の使い方）

  1. Logic で、読み込み先のトラック（Quick Sampler の入ったソフトウェア音源のトラック）を選び、Quick Sampler の画面を開いておきます（Logic Magician ではハイフン）
  2. アプリの読み込み先を Quick Sampler にします（コマンド+1）。初めは Quick Sampler になっています
  3. 検索語・キー・BPM・種別・パックを入れて、検索語の欄でリターン（または「検索を実行」）。BPM は前後 4 の範囲で探します。パックの欄は、パックの名前のあとに、中のサンプルの数を読みます
  4. 検索結果一覧で上下矢印。1 行ずつ、名前・BPM・キー・種別・長さを読みます。スペースで試聴します（もう一度押すと止まります）
  5. 決めたらリターン。Logic が前に出て読み込み、終わるとこのアプリに戻って結果を読みます（5 秒ほどかかります）
  6. MIDI 鍵盤で弾いて確かめます。Logic が後ろにあっても鳴ります。次の素材を選んでリターン、を繰り返します

読み込んでいる間

Logic のメニューや「開く」ダイアログが開いたり閉じたりし、その様子を VoiceOver が読むことがあります。終わるまで、キーボードやマウスに触らずに待ってください。途中で失敗したら、アプリが「開く」ダイアログを閉じて元に戻し、理由を読み上げます。

読み込むたびに、Flex（速さを変えずに音程を変える機能）を設定どおりにします。既定は「ループなら入れる、ワンショットと効果音は切る」です（8 章）。

6. Drum Machine Designer のパッドへ読み込む

DMD のパッドに、聴いて選んだワンショットを 1 つずつ入れてドラムキットを組みます。DMD のパッドは 48 個（16 個ずつ 3 ページ）で、パッドの中身は 1 つずつ Quick Sampler です。

  1. Logic で DMD のトラックを選び、DMD の画面を開いておきます。インスペクタも表示しておきます（Logic の I のキー）。パッドのチャンネルを操作するためです
  2. アプリの読み込み先を DMD のパッドにします（コマンド+2）。アプリが Logic からパッドの一覧を読み、「パッド」の欄に 48 個並べます（「パッド 3、D1 SNARE 1。空き」のように読みます）
  3. 入れる先のパッドを選びます。コマンド+右ブラケット（]）で次、コマンド+左ブラケット（[）で前のパッドへ移り、中身を読みます。48 の次は 1 に戻ります。日本語配列では、右ブラケットは L の 3 つ右（む のキー）、左ブラケットは P の 2 つ右（半濁点 ゜ のキー）です
  4. 一覧で素材を選んでリターン。1 つのパッドで 6 秒ほどかかります。読み込んだら、次のパッドへ進みます（コマンド+S の設定で切れます）
  • 空のパッドには、Quick Sampler を入れてから読み込みます。読み込んだら、パッドの名前を素材の名前にします（そのままだと「Empty Pad」などのままで、耳で区別できないため）
  • 読み込む間、DMD の画面はいったん閉じて、また開きます（DMD の中に出る Quick Sampler の画面からは読み込みません。そこから読み込むと Logic が落ちたことがあるためです）
  • Quick Sampler 以外の音源が入っているパッドには読み込みません。理由を読み上げます
  • Logic の側でパッドの中身を変えたときは、コマンド+T でパッドの一覧を読み直します

7. オーディオトラックに貼る（テンポとキーを合わせる）

ループ素材を、プロジェクトのテンポとキーに合わせた音にしてから、Logic のオーディオトラックに貼ります。ffmpeg が要ります（3.5）。

7.1 手順

  1. Logic で、再生位置を貼りたい小節に置いておきます。インスペクタも表示しておきます（I のキー）
  2. アプリの読み込み先をオーディオトラックにします（コマンド+3）。「読み込み先をオーディオトラックにしました。貼り付け先は Audio 1。120 BPM、Cメジャー」のように読みます。トラックの番号・拍子・再生位置・貼る小節が空いているかまで聞くときは、コマンド+T です
  3. 貼り付け先のトラックを選びます。コマンド+右ブラケット（]）で次、コマンド+左ブラケット（[）で前のオーディオトラックです。ソフトウェア音源のトラックは飛ばし、端まで行くと反対の端に戻ります。移ると、まずトラックの名前を読み、続けて貼る小節が空いているか（何があるか）を読みます。「貼り付け先のトラック」の欄で選んでも、Logic の側で選んでもかまいません
  4. 一覧で素材を選び、スペースで元の音、シフト+スペースでテンポとキーを合わせた音を試聴します。合わせた音の読み上げは「合わせた音、Even、120 BPM。」のように合わせ方から始まります。合わせた音を作るときは、合図の音が鳴ります
  5. 決めたらリターン。1.5 秒ほどで貼り、どこに何を貼ったか、何に合わせたかを読みます

シフト+スペースで聴いた音と同じものを貼ります。スペースとシフト+スペースを交互に押すと、止めずに切り替わります。

7.2 テンポの合わせ方（ハーフ・Even・ダブル）

「テンポの合わせ方」の欄で選びます。コマンド+シフト+T でも、ハーフ、Even、ダブルの順に送れます。基準はプロジェクトの BPM です（素材の BPM ではありません）。表は 3 行で、列は「合わせ方」「素材を何 BPM にするか」「120 BPM のプロジェクトでは」の 3 つです。

合わせ方素材を何 BPM にするか120 BPM のプロジェクトでは
ハーフプロジェクトの BPM の半分60 BPM
Even（既定）プロジェクトの BPM120 BPM
ダブルプロジェクトの BPM の倍240 BPM

たとえば 102 BPM・2 小節のループなら、ハーフで 8 秒（プロジェクトの 4 小節）、Even で 4 秒（2 小節）、ダブルで 2 秒（1 小節）になります。素材の BPM はファイル名のとおりに数えます。87 BPM の素材を 174 BPM のプロジェクトに Even で入れると倍の速さに縮めるので、そのまま使いたいときはハーフを選びます。Even で大きく伸び縮みするときは「ハーフにすると、伸び縮みが小さくなります」と添えます。

7.3 キーと移調

  • 「合わせるキー」の欄の既定は、プロジェクトのキー（Logic のコントロールバーの Key Signature）です。「合わせない（素材のまま）」や、24 のキーのどれかも選べます。コマンド+K で、プロジェクトのキーに合わせるか、合わせないかを切り替えます
  • 平行調は移調しません（A マイナーの素材を C メジャーのプロジェクトに入れても、そのまま）。ずらすときは近い向き（6 半音下げる〜5 半音上げる）です
  • 「移調」の欄で、キーを合わせたうえで、さらに半音ずつ上げ下げできます（12 半音まで）
  • テンポの合わせ方・キー・移調は保存しません。アプリを閉じると、Even・プロジェクトのキー・移調しない、に戻ります（前の曲の値のまま次の曲に貼らないため）

7.4 貼ったあとの再生位置

コマンド+S の「オーディオトラックに貼ったあとの再生位置」で、3 つから選びます。

  • 貼ったオーディオの終わりへ進める（既定）。続けてリターンを押すと、ループが順に並びます。終わりが小節の途中なら、次の小節の頭へ進めます
  • 貼ったオーディオの頭に置く。すぐ再生して、貼った音を聴けます
  • 動かさない

7.5 気をつけること

  • Logic は、再生位置のある小節の頭に貼ります（拍の途中でも小節の頭に寄ります）。設定の「オーディオトラックに貼る位置」を「いちばん近い小節の頭」にすると、小節の終わり近くで止めたとき、次の小節に貼ります
  • 再生中は再生位置を動かしません。続けて並べたいときは、止めてからリターンを押します
  • ソフトウェア音源のトラックには貼れません。新しいオーディオトラックは、Logic でオプション+コマンド+A です
  • 選ばれているトラックが 2 つ以上あるときは、Logic のインスペクタに出ているトラックに貼ります
  • 空のモノラルのトラックにステレオの素材を貼ると、Logic がトラックをステレオに切り替えます（そう読み上げます）
  • 貼ったあとに Logic のテンポを変えても、貼ったループは追いかけません。テンポを変えたら貼り直します
  • ワンショットと効果音は、テンポを合わせません（キーが分かれば、キーだけ合わせます）。BPM やキーが分からない素材は、分からない部分を合わせずに貼り、そう言います
  • MP3・CAF・FLAC・M4A の素材も合わせられます（WAV に直してから作ります）
  • Logic が遅れてインスペクタが切り替わらないときは、そこで止めて、そう言います。コマンド+T で確かめ直せます
  • 素材にテンポ情報やマーカーが入っていると、Logic が「テンポ情報をこのプロジェクトに読み込みますか?」「マーカーをこのプロジェクトに読み込みますか?」と尋ねます。アプリは素材をプロジェクトに合わせて貼るので、「読み込まない」と答えます（そう読み上げます。プロジェクトのテンポとマーカーは変わりません）
  • Drum Machine Designer の画面が開いていると、Logic がオーディオトラックへの貼り付けを受け付けないことがあります。そのときはアプリが DMD の画面を閉じてから貼ります（そう読み上げます）

8. 速さを変えずに音程を変える（Flex）

Quick Sampler は、そのままだと鍵盤で音程を変えると速さも変わります（高い鍵盤ほど速く短く鳴ります）。波形表示の右下の Flex を入れると、音程を変えても速さは変わりません。このボタンは VoiceOver の移動では届かず、名前もありません。

  • アプリは、読み込むたびに Flex を設定どおりにします。既定は「素材に合わせる」で、ループなら入れ、ワンショットと効果音は切ります（Flex の状態は次の素材にも引き継がれるので、毎回決め直します）
  • 読み込んだあとに切り替えるときは、アプリでコマンド+シフト+F、Logic の中ならコントロール+シフト+T（Keyboard Maestro の補助）
  • Follow Tempo（Flex の隣）を入れると、プロジェクトのテンポに合わせて鳴ります。既定は切ります（素材のテンポを Logic が正しく知らないと、違う速さになるため）。アプリでコマンド+シフト+P、Logic の中ならコントロール+シフト+P です。Flex を入れたときだけ効きます

オーディオトラックに貼るときは、Flex を使いません（アプリが合わせた音を作ってから貼るため）。

11. Logic の中で使うキー（Keyboard Maestro の補助）

Quick Sampler の Sample name の欄と Flex のボタンは、VoiceOver の移動では届きません。Keyboard Maestro の補助（3.6 で入れます）が、次の 3 つのキーで代わりに押します。Logic Pro の中だけで効きます。どれも、先に Quick Sampler の画面を開いておきます。表は 3 行で、列は「キー」「動作」の 2 つです。

キー動作

コントロール+シフト+L の使い方

  2. 下矢印で「Load Audio File…」まで降りて、リターン

  • Logic Magician を使っている場合、「開く」ダイアログで文字を打つときは、Logic Magician の 1 文字のキーが文字を奪うことがあります。Logic Magician を一時的に切ってから（コントロール+エスケープ）打ち、終わったら戻します

13. 困ったとき

読み上げが聞こえない

VoiceOver が入っているかを確かめます。アプリは、読ませた文を時刻と一緒に記録（~/Library/Logs/LogicSampleLoader.log の「[読み上げ]」の行）に残します。記録にあるのに聞こえないときは、VoiceOver がほかの読み上げを読んでいた可能性があります。いちばん下の行にも、最後の文が出ています。

「アクセシビリティの許可がありません」と言われる

3.3 のとおりに許可を入れ、アプリを開き直します。新しい版に入れ替えたあとなら、一覧の Logicサンプルローダー を消してから入れ直します。

「Quick Sampler の画面が開いていません」と言われる

Logic で、読み込み先のトラックの Quick Sampler の画面を開いてから、もう一度リターンを押します。

「Drum Machine Designer の画面が開いていません」「インスペクタが表示されていません」と言われる

Logic で DMD の画面を開き、インスペクタを表示（I のキー）してから、もう一度押します。

「Splice の索引が読めません」と言われる、検索しても何も見つからない

コマンド+R で索引を作ります。「Splice のフォルダが見つかりません」と言われたら、操作メニューの「Splice のフォルダを選ぶ」で、素材の入っているフォルダを選びます。

「ffmpeg が見つかりません」と言われる

3.5 のとおりに Homebrew で ffmpeg を入れ、アプリを開き直します。

「オーディオトラックではありません」「トラックが選ばれていません」と言われる

Logic でオーディオトラックを選んでから、もう一度リターンを押します。アプリのコマンド+右ブラケット（]）でも選べます。

「Logic が応えません」「インスペクタがまだ … のまま」と言われる

Logic が、トラックの選択やインスペクタの切り替えに追いついていません。少し待ってから、コマンド+T で確かめ直すか、もう一度押します。

貼ったループがメトロノームと合わない

アプリは素材の BPM をファイル名から読みます。名前の BPM が倍か半分の数え方のときは、ハーフかダブルを選んで貼り直します。ループの長さが BPM と合わないときは「テンポがずれるかもしれません」と添えています。

Keyboard Maestro のキーが効かない

Keyboard Maestro の編集画面で、グループ「Logicサンプルローダー 補助」のマクロが有効か確かめます。結果が読まれないときは、VoiceOver ユーティリティで AppleScript による制御を許可します。アプリを移したあとなら、アプリを一度開きます（「Logicサンプルローダーが見つかりません」と言われたときも同じです）。

それでも分からないとき

記録（~/Library/Logs/LogicSampleLoader.log）に、アプリの経過（「[補助]」の行）と読み上げた文が残っています。どこで止まったかの手がかりになります。

14. 取り除き方

  1. アプリを終了し（コマンド+Q）、アプリケーションフォルダの「Logicサンプルローダー.app」をゴミ箱へ入れます
  2. 設定と索引を消すなら、~/Library/Application Support/LogicSampleLoader をゴミ箱へ入れます。試聴の音は ~/Library/Caches/LogicSampleLoader、記録は ~/Library/Logs/LogicSampleLoader.log です
  3. ~/Music/LogicSampleLoader（素材の複製と合わせた音）は、それを使っている Logic のプロジェクトが無いときだけ消します
  4. Keyboard Maestro の補助を入れていたら、Keyboard Maestro の編集画面で、グループ「Logicサンプルローダー 補助」を削除します
  5. システム設定の「プライバシーとセキュリティ」→「アクセシビリティ」の一覧から、Logicサンプルローダー を消します

15. できないこと・気をつけること

  • Logic Pro は英語か日本語の表示で使います（2 章）。Logic の版が変わって画面の作りが変わると、部品が見つからなくなることがあります
  • Intel の Mac では動きません
  • 読み込んでいる間は、キーボードやマウスに触らないでください。アプリが Logic を前に出して操作しています
  • DMD のパッドには、Quick Sampler のパッドだけ読み込めます
  • 貼ったループは、あとで Logic のテンポを変えても追いかけません
  • 素材の BPM とキーは、ファイル名から読みます。名前に書かれていない素材は、テンポとキーを合わせられません
  • 素材の複製と合わせた音（~/Music/LogicSampleLoader）は、読み込んだプロジェクトが使っています。消すと、プロジェクトの音が鳴らなくなります
